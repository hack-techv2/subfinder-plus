# Security Policy

## Supported versions

Security fixes are evaluated for the current development branch, `dev`, and the latest published Subfinder-plus release. Please include the version, commit, or release tag you tested when reporting an issue.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's security advisory form:

https://github.com/hack-techv2/subfinder-plus/security/advisories/new

Do not disclose credentials, target data, or exploit details in public issues, discussions, pull requests, fixtures, or logs. Provide only the minimum information needed for maintainers to reproduce and assess the issue through the private report.

## Third-party passive sources

Report a vulnerability in Subfinder-plus when its code or release artifacts create a security issue. Third-party passive-source outages, rate limits, response changes, or other provider behavior changes are not necessarily vulnerabilities in Subfinder-plus; report those as behavior issues with a clear, sanitized description instead.
